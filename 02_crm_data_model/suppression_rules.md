# Global Suppression Rules

## Suppress From All Email Campaigns If

- Email Opt-Out = true
- Do Not Market = true
- Active complaint = true

## Suppress From SMS If

- SMS Opt-Out = true
- No valid phone number
- Contact replied STOP

## Suppress From Pest Upsell If

- Pest Plan Status = Active
- Pest service already booked
- Pest treatment already completed

## Suppress From Termite Workflow If

- Termite treatment already booked
- Termite treatment completed
- Customer submitted termite quote form
- Open complaint related to termite/WDO report

## Suppress From Agent Reactivation If

- Active inspection/referral in progress
- Agent is currently in another active agent sequence
- Agent recently replied and BD task is open
