# Email Design System

## Agent Emails

- Clean B2B letter-style HTML.
- White background.
- One subtle orange highlight card.
- Minimal graphics.
- Calm, professional tone.

## Homeowner Pest Emails

- More promotional design is acceptable.
- Use address/date personalization.
- Strong CTA.
- Avoid excessive color blocks.

## Termite/WDO Emails

- Cleaner and more serious than pest upsell.
- Use property address.
- Use "report context" as trust anchor.
- Use calm urgency, not fear.
