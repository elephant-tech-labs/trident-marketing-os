# Trident Marketing OS

This repo is the source of truth for Trident Inspection Group's email/SMS lifecycle marketing system.

It documents:
- Campaign strategy
- CRM fields and segments
- Zoho Campaigns setup
- Email/SMS assets
- CTA links and source codes
- QA checklists
- Performance logs
- Audit prompts for ChatGPT/Codex

## Current Growth Engines

1. **Agent Referral Engine**
   - Goal: Make Trident memorable, easy to reach, and trusted by real estate agents when inspection timing matters.

2. **Homeowner Lifetime Value Engine**
   - Goal: Convert inspection, termite, pest, and specialty-service clients into repeat services, pest plans, reviews, referrals, and long-term property care.

## Important Rule

Do not commit private customer exports, real inspection reports, real WDO reports, or personally identifiable customer data to this repo.
Use sanitized samples only.
