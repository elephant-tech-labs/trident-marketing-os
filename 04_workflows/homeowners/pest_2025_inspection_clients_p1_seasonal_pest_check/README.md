# TIG | Pest 2025 Inspection Clients P1 - Seasonal Pest Check

This workflow is for homeowners who completed a Trident home inspection in 2025 and are eligible for pest protection follow-up.

This is separate from the existing Pre-2025 pest activation workflow.

## Strategic Role

The campaign uses the prior home inspection relationship as the trust anchor and introduces Trident Pest Control as the next practical property-care step.

The message should feel:

* timely
* helpful
* seasonal
* calm
* service-oriented
* not alarmist
* not overly salesy

## Core Offer

A complimentary first pest check / first pest service when the homeowner chooses to start pest protection.

## Primary Goal

Convert 2025 inspection clients into pest check / pest protection inquiries.

## Primary CTA

Book My Complimentary Pest Check

## Secondary CTA

Reply PEST or call/text 949-294-1188.

## Important Rule

Do not reuse Pre-2025 copy word-for-word. This audience is more recent and should receive a warmer, softer, more seasonal message.
